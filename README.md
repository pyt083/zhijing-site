# 智影 Insai InVision — 官网复刻版

一站式 AI 视频与内容生成平台的产品展示页，按《智影用户手册 V3.0》整理全部功能亮点。

## 内容结构
- Hero：一句话出片的价值主张 + 创作台界面示意
- 核心能力：创意落地 / Agent 协作 / 素材裂变
- 两种协作方式：极速成片 与 深度共创
- 功能全景：27 项能力，可按 6 类筛选，对应手册一至五章
- 创作流程：brief → Agent 追问 → 定方向 → 分镜
- 场景方案：前贴生成 / 卖点展示 / 商品特写 / 图生视频
- 企业版：企业主账号 10 个子模块 + 开放平台 API
- 价格、常见问题、页脚

## 技术
纯静态：`index.html` + `assets/css/main.css` + `assets/js/main.js`，无构建依赖，可直接托管在 GitHub Pages。

图片位于 `assets/img/`（webp，压缩后 44–130KB）。

## 本地预览
直接用浏览器打开 `index.html`，或 `python -m http.server 8080`。
